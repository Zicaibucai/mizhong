# Preview 2.0 全站设计方案

## 目标

把原设计预览从单页概念升级为可正式上线、可持续维护的三语 B2B 产品官网。首页、产品目录、搜索、产品详情、空状态与 404 使用同一套视觉和交互规则；后台、内容模型和商品发布流程保持不变。

## 品牌方向：Material Intelligence

- 品牌红：来自商标顶面，承担主要按钮、链接、编号和交互反馈，不做大面积铺色。
- 深酒红与炭黑：来自商标立体暗面，承担首屏、页头和页脚，保持 B2B 所需的稳重感。
- 银灰：来自商标金属面，用于辅助文字、分隔线与材料层次。
- 暖白：承载产品和长内容，缓和红、灰之间的工业感。
- 织线、经纬网格、编号、细分隔线：来自纺织材料和技术图纸，而不是通用科技光效。
- 真实商品与真实后台素材优先；没有素材时使用明确的抽象织纹，不伪造工厂、证书、产能或客户。

### 商标配色 2.0

| 角色 | 核心色 | 用法 |
| --- | --- | --- |
| 品牌红 | `#C6222D` | 主按钮、链接、当前状态与品牌识别 |
| 深酒红 | `#75191F` | 品牌红的悬停、按压与强调层次 |
| 炭黑酒红 | `#160A0D` | 首屏、页头、页脚与高对比背景 |
| 商标银灰 | `#A9AAAD` | 材料图形、辅助信息与结构分隔 |
| 暖白 | `#FCFBFA` | 正文、产品目录与表单背景 |

配色面积遵循约 `70 / 20 / 10`：暖白与浅灰占 70%，炭黑与深酒红占 20%，亮品牌红不超过 10%。绿色只保留给 WhatsApp 等具有固定平台识别的入口，黄色只保留给后台警告等语义状态。

## 信息架构

### 首页

1. 品牌主张与浏览产品 / 发起询盘。
2. 已发布商品优先的编辑式产品墙；没有商品时如实展示品类。
3. 公司介绍与市场定位。
4. 采购流程。
5. 质量流程与真实证书素材。
6. 联系渠道与询盘入口。

### 产品目录与搜索

- 深色索引页头，快速建立与首页一致的品牌语气。
- 搜索、分类、排序和结果数量集中在产品网格之前。
- 桌面使用粘性分类索引；移动端使用原生 details 折叠面板。
- 商品卡片优先显示名称、分类、价格、MOQ、尺寸和询价动作；悬停视频只做增强。

### 产品详情

- 首屏采用“媒体 + 贸易信息”双栏。
- 价格、计价单位、MOQ、尺寸在首屏内完整出现。
- WhatsApp、邮件、电话和询盘按钮无需滚到底即可触达。
- 产品说明、规格、应用使用编辑式标签列与正文列。
- 图库、询盘和相关商品组成后续转化路径。

## 响应式原则

- 手机端不复制桌面的巨大留白，保持连续内容密度。
- 可点击目标不小于 40px；关键表单控件为 44–48px。
- 手机产品列表单列、平板双列、桌面三列；首页产品墙使用双列拼贴。
- 联系悬浮轨只在桌面出现，避免遮挡移动端正文。

## 动效与无障碍

- 动效只修改 opacity、transform 和 clip-path，不触发布局抖动。
- 页面内容的服务器输出默认可见；IntersectionObserver 只做增强。
- `prefers-reduced-motion`、无 JavaScript、打印模式均显示完整终态。
- 搜索、分类、排序、分页、媒体切换均保留真实链接或原生表单降级路径。
- 焦点状态、跳过导航、语义标题与媒体替代文本继续保留。

## 维护策略

- 正式首页与 `/design-preview` 共用同一个 `PreviewHome`，不再维护两份首页。
- 三种语言继续使用现有内容层、商品库和联系方式。
- `design-preview` 保留为 noindex 的评审入口；正式语言首页使用可索引 metadata。
- 视觉样式限定在 `[data-preview]` 根节点下，不污染后台管理界面。
